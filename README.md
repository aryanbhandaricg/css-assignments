## Run locally

1. Clone or download this repository.
2. Open it in VS Code.
3. Open the root index.html in a browser, or use Live Server.
4. Choose a project from the gallery. Each project can also be opened directly from its folder.

## Project structure

- Every assignment has its own folder and index.html.
- styles.css holds the shared styles, grouped by project.
- The pages use HTML and CSS only and adjust for smaller screens.

These are static layout exercises. The calculator keys, search fields, and media controls are visual elements; they are not connected to application logic.

Reference: [CodingGita CSS Level 2 assignments](https://github.com/codinggita/CGxSU_Semester_1/tree/main/Semester_1/html_css_js%28sem_01%29/CSS/00.assignment/02.level_2).
